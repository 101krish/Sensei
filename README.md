# Sensei - AI Resume & Cover Letter Builder

An intelligent, AI-powered application that guides engineers and professionals through creating outstanding resumes and customized cover letters, built on Next.js.

## Key Features
- **Template Selector**: Choose from standard single-column engineering structures or creative sidebar grids.
- **Auto-Save Hook**: Periodic interval state saver preventing data loss during form edits.
- **Sanitizer Parsing**: Strict client-side filter removing markdown tags and scripts from AI output.
- **Status Toast alerts**: Smooth sliding alert card feedback indicating save, validation, or system errors.

## Tech Stack
- Next.js (App Router)
- React
- Clerk Auth integration
- Prisma ORM (Database connection)
- Inngest (Background workflows scheduling)
- Tailwind CSS
